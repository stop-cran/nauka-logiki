# Русская аудиокнига

Общий движок и инструкция находятся в
[stop-cran/book-skills](https://github.com/stop-cran/book-skills/tree/main/.github/skills/audiobook-from-markdown).
Здесь хранится только конфигурация книги `book.json`; исходные выпуски не меняются.

Текущий профиль выбирает **ровно выпуски 1–29**, без README, голос
`ru-RU-Lev:MAI-Voice-2` и язык SSML `ru-RU`. Заголовок каждого трека начинается
с номера выпуска. Первый трек содержит краткое указание, что это подготовленный
с помощью ИИ конспект, а не текст самого Гегеля; оно также записывается в ID3.

Укажите путь к общему репозиторию в `BOOK_SKILLS_ROOT`. Из этой папки:

```powershell
$engine = Join-Path $env:BOOK_SKILLS_ROOT '.github\skills\audiobook-from-markdown\reference\synthesize.py'
python $engine --project .\book.json --dry-run --all
python $engine --project .\book.json --resource '<your-resource>' --probe-max-chars
python $engine --project .\book.json --resource '<your-resource>' 01-от-школьной-логики-к-диалектике --limit-chunks 2
```

**После одобрения пробной записи и состава книги**:

```powershell
python $engine --project .\book.json --resource '<your-resource>' --all
```

Порядок проверки, вход через `az login`, зависимости, измерение лимита и возобновление
описаны в общей инструкции. Перед полным запуском нужно прослушать пробную запись;
проверка формата MP3 не заменяет прослушивания.

Принятая для этого корпуса политика: пропускать итоговые таблицы, уже развёрнутые
в прозе; в трёх схемах выпусков 2, 4 и 5 читать слова в порядке документа, без
рамок и линий. Произвольную графическую топологию движок не истолковывает.
Параграфы, ссылки и основные математические знаки подготавливаются по-русски;
падеж ссылочного слова согласуется с поддерживаемым предлогом, а римские ссылки
читаются как части выпуска, не как номера выпусков. Неподдерживаемый неоднозначный
контекст останавливает подготовку, а не угадывается.
Неоднозначные падежные контексты заданы в `reference_cases` этой книги; они не
вшиты в общий движок.
Это относится и к управлению существительным, глаголом или причастием; для
ссылок-подлежащих после таких слов именительный падеж указан явно.
Смысл формул и цитат не переписывается. Косые черты, индексы и немецкие глоссы
требуют проверки на слух.

Готовые файлы находятся в `out\`: MP3 и `*.manifest.json` для каждого выпуска.
Манифест связывает запись с исходником, настройками, версией движка и хешем аудио.
Промежуточный PCM-кеш позволяет продолжить прерванный запуск; он не означает,
что выпуск готов. Изменённые или старые записи без манифестов требуют явного
`--force` либо другой выходной папки. `--force` сохраняет проверенные PCM-фрагменты
для возобновления; добавлять `--refresh-cache` нужно только для намеренного повторения
всех вызовов TTS. Аудио, транскрипты, кеш и измеренные лимиты
не добавляются в Git. Автоматическая публикация записей не выполняется.

Для плана запуска, выбора полных пробных фрагментов, записи одобрения и итоговой
проверки используйте общий `reference\workflow.py` по инструкции `book-skills`,
а не отдельные скрипты этой книги. Файлы `*.run.json` и `*.verification.json`
хранятся в игнорируемой папке `out\`. Проверка не вызывает Azure, не синтезирует
и не меняет готовые записи. Программная запись одобрения не доказывает прослушивания.
